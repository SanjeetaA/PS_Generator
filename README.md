# Secure Python Password Generator

A lightweight command-line tool built in Python that generates cryptographically strong, unpredictable passwords.

## Features
- Uses Python's `secrets` module for cryptographically secure randomness.
- Guarantees at least one lowercase letter, uppercase letter, number, and symbol.
- Validates user input to prevent crashes from invalid entries or short lengths (minimum 6 characters).

## How to Run
1. Make sure Python 3 is installed.
2. Run the script in your terminal:
   ```bash
   python password_gen.py
